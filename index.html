Algorithm

How the search works

1

Validate the input

The number must be even and greater than 2. Anything else is rejected with an error message — exactly the rule the original program enforced.

if n <= 2 or n % 2 != 0
2

Try each candidate a

The search walks a upward from 2 to n / 2. Beyond the halfway point, pairs would only repeat in mirror order, so it stops there.

for a in range(2, n // 2 + 1)
3

Compute the partner b

For every candidate, the partner is fixed: b = n − a. If both turn out to be prime, their sum is n and the conjecture holds for this number.

b = number - a
4

Test primality by trial division

After handling 2 and the evens, a candidate is tested by dividing it by every odd number up to its square root — if none divides it, it is prime.

for i in range(3, int(n**0.5)+1, 2)
